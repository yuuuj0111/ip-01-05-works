# 互动编程作业 · 几何构成

**作者：** 虞静　|　**课程：** 互动编程　|　**编号：** ip-01-05

用 p5.js 写的一条鱼：头是一个橘色椭圆，身体是 10 片由橘到黄渐变的三角形，
尾巴是两根橙色长条，上方六颗尺寸递增的气泡。整个画面没有一张贴图，全部由代码生成。

静态效果图：[`preview.png`](preview.png)
动态效果视频：[`demo.mp4`](demo.mp4)

---

## 一、作品说明

### 1. 静态构成

一条向左游的鱼，所有元素都落在几何图元上：

| 部位 | 图元 | 做法 |
| --- | --- | --- |
| 鱼头 | 椭圆 | `ellipse(100, 200, 50, 60)` |
| 鱼身 | 10 个三角形 | `for` 循环，每片右移 35px、缩小 3px |
| 鱼尾 | 两个矩形 | 上下各一根橙色长条 |
| 眼睛 | 两个同心圆 | 白眼球 + 黑瞳孔 |
| 气泡 | 6 个圆 | `for` 循环，`i % 2` 控制上下错位 |

**色彩逻辑：** 背景是浅蓝水面 `(180, 220, 230)`，鱼身从橘色 `(255, 150, 50)`
逐片过渡到黄色 `(255, 222, 50)`，用递增量 `+8` 让鱼尾自然变亮。
这种「同一图元 + 参数递增」的写法，颜色和形状的节奏是同一套变量推出来的，
所以整条鱼的秩序感是算出来的，不是一片片摆出来的。

### 2. 动态构成

动态版本让这条鱼活起来：鱼嘴一张一合，把从右边游过来的三角形一个个吃掉。

- 时间：`frameCount` 每帧自己往前走，不需要任何按键
- 鱼嘴开合角度由 `sin(frameCount)` 驱动，一开一合就是一个周期
- 三角形的坐标逐帧左移，进入鱼嘴范围后重置到右侧，形成循环

静态是「一个瞬间的定格」，动态是「同一套几何体 + 一个时间参数」。

## 三、运行方式

**方式一（本地）：** 直接双击 `index.html`，浏览器会打开画布，无需安装任何东西。

**方式二（在线）：** 访问本仓库的 GitHub Pages 地址即可看到实时运行的画面。

## 四、开发环境

- 编辑器：Visual Studio Code
- 绘图库：p5.js 2.3.3
- 画布尺寸：600 × 400
- 关键 API：`createCanvas` / `triangle` / `ellipse` / `rect` / `for` 循环 / `noLoop`

## 五、可以继续改的地方

`sketch.js` 里鱼身循环的两个数字是整条鱼的「基因」：

```js
for (let i = 0; i < 10; i++) {   // 10 → 片数，改成 6 就是一条短鱼
  let x = 120 + i * 35;          // 35 → 片距，改成 20 鱼身会更密
  let size = 70 - i * 3;         // 3  → 每片的收缩量，改成 5 鱼尾会更尖
```

改这三个数字中的任何一个，都会得到一条不同体型的鱼——这是参数化绘图最直接的乐趣。
